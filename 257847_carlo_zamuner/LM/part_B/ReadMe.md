# Istruzioni per l'utilizzo

## Modalità di valutazione (eval)

Tutti i parametri dei quattro setup sono configurati automaticamente in modalità di valutazione (eval). Eseguendo `python main.py`, verranno valutati tutti i modelli con i rispettivi file `.pt` presenti nella directory. I risultati ottenuti rappresentano, con un margine di errore inferiore all'1% dovuto alla variabilità dei dati, i valori riportati nel report.

## Modalità di addestramento (train)

Nel caso si desideri utilizzare la modalità di addestramento per testare una configurazione da terminale, in tutti e quattro i setup è già impostata la configurazione che ha prodotto i migliori risultati per ogni parte del progetto.
